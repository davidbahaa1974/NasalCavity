# 🏥 Medical VR Simulation — Nasal Cavity Inspection

A Unity project module demonstrating tool insertion and navigation within a confined anatomical space, built for medical training and surgical simulation purposes.

## 👃 Nasal Cavity Inspection

**Functionality:** Simulation of tool insertion and interaction within a confined anatomical space.

**Key Tech:** Collision detection and confined space navigation constraints.

## 📂 Documentation

Detailed technical documentation for this module is available at:

* `/Documentation/Nasal Cavity.md`

## 🛠️ Built With

* **Engine:** Unity 6.2 (LTS)
* **Pipeline:** Universal Render Pipeline (URP)
* **Language:** C#

## 🚀 Getting Started

1. Clone the repository.
2. Open the project in Unity Hub.
3. Navigate to `Assets/Scenes` to find the Nasal Cavity Inspection scene.
4. Press Play to test the interaction.
